ТЕХНИЧЕСКОЕ ЗАДАНИЕ
на разработку программы «Мой Дневник»

1. Общие сведения
Полное наименование: мобильная программа «Мой Дневник» для студентов колледжа.
Заказчик: студенческий совет колледжа. Разработчик: студент группы _______________
Сроки разработки: с 1 ноября по 30 декабря текущего года.

2. Назначение программы
Программа предназначена для того, чтобы пользователь мог вести расписание занятий, записывать домашние задания и получать напоминания о дедлайнах. Пользователь видит все свои задачи на одном экране и не забывает про сдачу работ.

3. Требования к функциям
Программа должна уметь:

· регистрировать пользователя по номеру телефона или почте;
· показывать расписание на неделю;
· добавлять домашнее задание через кнопку «+»;
· отправлять напоминание за сутки до дедлайна;
· показывать статистику выполненных заданий;
· менять тему оформления (светлая / тёмная) по кнопке в настройках.

4. Требования к интерфейсу
Интерфейс должен быть простым и понятным даже начинающему пользователю. Главный экран содержит расписание на сегодня, внизу располагается панель навигации из четырёх кнопок: «Расписание», «Задания», «Статистика», «Настройки». Цветовая гамма – спокойная, шрифт – не меньше 14 пт.
Программа должна работать на телефонах с Android 10 и выше.

5. Этапы разработки
Анализ требований и составление ТЗ
Проектирование интерфейса (макеты экранов)
Написание кода программы
Тестирование и исправление ошибок
Публикация программы в магазине приложений

Порядок приёмки: программа считается принятой, если все функции из раздела 3 работают без ошибок и пользователь может выполнить их не более чем за три нажатия.
